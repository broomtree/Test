# 🚀 3D 우주 탐험 게임

무한한 우주 공간을 자유롭게 떠돌아다닐 수 있는 3D 우주 탐험 게임입니다.

## ✨ 특징

- **무제한 3D 공간**: 제한 없이 모든 방향으로 자유롭게 이동
- **아름다운 우주 환경**: 10,000개 이상의 별, 행성, 소행성, 성운
- **직관적인 조작**: 키보드와 마우스로 쉽게 조작
- **실시간 물리**: 관성과 마찰이 적용된 현실적인 움직임
- **다양한 천체**: 고리가 있는 행성, 회전하는 소행성, 발광하는 성운

## 🎮 조작법

### 키보드
- **W**: 앞으로 이동
- **S**: 뒤로 이동
- **A**: 왼쪽으로 이동
- **D**: 오른쪽으로 이동
- **Space**: 위로 이동
- **Shift**: 아래로 이동
- **Q**: 왼쪽으로 회전
- **E**: 오른쪽으로 회전

### 마우스
- **드래그**: 시점 회전 (상하좌우)

## 🛠️ 실행 방법

1. 웹 서버에서 파일 실행:
```bash
# Python 3가 설치되어 있는 경우
python -m http.server 8000

# Node.js가 설치되어 있는 경우
npx http-server
```

2. 브라우저에서 열기:
```
http://localhost:8000
```

또는 `index.html` 파일을 최신 웹 브라우저(Chrome, Firefox, Edge 등)에서 직접 열어도 됩니다.

## 🌌 게임 요소

### 별
- 10,000개의 별이 무작위로 배치
- 다양한 색상 (흰색, 파란색, 노란색)

### 행성
- 8개의 독특한 행성
- 일부 행성은 토성처럼 고리를 가짐
- 각 행성은 자체 조명과 발광 효과
- 서로 다른 속도로 회전

### 소행성
- 200개의 소행성이 우주에 분산
- 각각 독립적으로 회전

### 성운
- 4개의 거대한 성운
- 반투명한 구름 효과

## 🎯 탐험 팁

1. 천천히 시작하세요 - 키를 살짝만 눌러도 관성으로 계속 움직입니다
2. 마우스로 시점을 조절하면서 주변을 둘러보세요
3. 행성 가까이 다가가 자세히 관찰해보세요
4. 화면 왼쪽 상단의 정보 패널에서 현재 속도와 위치를 확인할 수 있습니다

## 🔧 기술 스택

- **Three.js**: 3D 그래픽 렌더링
- **JavaScript**: 게임 로직
- **HTML5/CSS3**: UI 및 스타일
