# 🚀 3D 우주 탐험 게임

순수 HTML, CSS, JavaScript만으로 만든 3D 우주 탐험 게임입니다.
외부 라이브러리 없이 Canvas 2D API를 사용하여 3D 효과를 구현했습니다.

## ✨ 특징

- **순수 웹 기술**: 외부 라이브러리 없이 HTML, CSS, JavaScript만 사용
- **자체 3D 엔진**: Canvas 2D API로 원근 투영과 3D 회전 구현
- **무제한 3D 공간**: 제한 없이 모든 방향으로 자유롭게 이동
- **풍부한 우주 환경**: 5,000개의 별, 20개의 행성, 300개의 소행성, 8개의 성운
- **직관적인 조작**: 키보드와 마우스/터치로 쉽게 조작
- **실시간 물리**: 관성과 마찰이 적용된 현실적인 움직임
- **다양한 천체**: 고리가 있는 행성, 회전하는 소행성, 발광하는 성운
- **성능 최적화**: FPS 카운터로 실시간 성능 모니터링

## 🎮 조작법

### 키보드
- **W**: 앞으로 이동
- **S**: 뒤로 이동
- **A**: 왼쪽으로 이동
- **D**: 오른쪽으로 이동
- **Space**: 위로 이동
- **Shift**: 아래로 이동
- **Q**: 왼쪽으로 회전
- **E**: 오른쪽으로 회전

### 마우스
- **드래그**: 시점 회전 (상하좌우)

## 🛠️ 실행 방법

1. 웹 서버에서 파일 실행:
```bash
# Python 3가 설치되어 있는 경우
python -m http.server 8000

# Node.js가 설치되어 있는 경우
npx http-server
```

2. 브라우저에서 열기:
```
http://localhost:8000
```

또는 `index.html` 파일을 최신 웹 브라우저(Chrome, Firefox, Edge 등)에서 직접 열어도 됩니다.

## 🌌 게임 요소

### 별
- 10,000개의 별이 무작위로 배치
- 다양한 색상 (흰색, 파란색, 노란색)

### 행성
- 8개의 독특한 행성
- 일부 행성은 토성처럼 고리를 가짐
- 각 행성은 자체 조명과 발광 효과
- 서로 다른 속도로 회전

### 소행성
- 200개의 소행성이 우주에 분산
- 각각 독립적으로 회전

### 성운
- 4개의 거대한 성운
- 반투명한 구름 효과

## 🎯 탐험 팁

1. 천천히 시작하세요 - 키를 살짝만 눌러도 관성으로 계속 움직입니다
2. 마우스로 시점을 조절하면서 주변을 둘러보세요
3. 행성 가까이 다가가 자세히 관찰해보세요
4. 화면 왼쪽 상단의 정보 패널에서 현재 속도와 위치를 확인할 수 있습니다

## 🔧 기술 스택

- **JavaScript (순수)**: 3D 렌더링 엔진 및 게임 로직
- **Canvas 2D API**: 그래픽 렌더링
- **HTML5/CSS3**: UI 및 스타일

## 💻 구현 내용

### 자체 제작 3D 엔진
- `Vector3` 클래스: 3D 벡터 연산 (덧셈, 뺄셈, 곱셈, 정규화, 내적, 외적)
- `Camera` 클래스: 카메라 위치, 회전, 시야각(FOV) 관리
- 원근 투영: Z 깊이 기반 원근 효과 구현
- 3D 회전: Yaw(좌우), Pitch(상하), Roll(회전) 변환 행렬 적용

### 렌더링 시스템
- 깊이 정렬: 먼 객체부터 렌더링하여 올바른 중첩 표현
- 원근 스케일링: 거리에 따른 크기 자동 조정
- 시야 절두체 컬링: 화면 밖 객체 렌더링 제외로 성능 최적화
- 그라데이션 효과: 행성 발광, 성운 효과

### 물리 시뮬레이션
- 속도 기반 이동: 관성 적용
- 마찰력: 속도 감쇠 효과
- 최대 속도 제한: 과도한 가속 방지
